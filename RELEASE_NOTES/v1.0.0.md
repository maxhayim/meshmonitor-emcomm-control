## SET Exercise Control v1.0.0 — Initial Release

Initial public release of the MeshMonitor SET exercise-control script.

### Included
- Runtime script: `mm_arrl_set.py`
- MeshMonitor Auto Responder support
- Check-ins with callsign, location, power source, and role
- Simulated SITREP logging
- Simulated addressed traffic logging
- Exercise status counts
- Eight timed exercise injects
- Explicit EXERCISE / SIMULATED labeling
- JSON / JSONL state and after-action logs
- Meshtastic and MeshCore support through MeshMonitor
- GitHub Pages documentation and standard project files

### Commands
```text
SET CHECKIN <CALLSIGN> <LOCATION> <POWER> <ROLE>
SET SITREP <LOCATION> <STATUS>
SET TRAFFIC <TO> <TEXT>
SET STATUS
SET HELP
```

### Deployment
- Python standard library only
- No pip dependencies

This release represents the original SET-only implementation before the project evolved into EmComm Control.
